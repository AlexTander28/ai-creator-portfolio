## Публикация

В репозитории только проверенный статический сайт и используемые медиа. GitHub Pages публикует ветку `main`, папку `/`; `.nojekyll` отключает обработку Jekyll. Корневая страница открывает `site/index.html`, относительные пути поддерживают имя репозитория в адресе.

Внутренние документы, исходные референсы, временные файлы, старые версии видео, персональные настройки и секреты сюда не включены. Для обновления используется повторная проверенная локальная сборка; не загружайте рабочую папку целиком.

Перед публикацией пройдены общий визуальный прогон Edge, проверки мобильной/планшетной версии, клавиатурного просмотра работ, адресов внутри подкаталога GitHub Pages и тесты семи демо. Это не заявление о полной сертификации WCAG или гарантии найма.
